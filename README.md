# Casper 个人项目文件夹

这个文件夹现在按用途分成 5 类，打开后可以直接按名字找东西。

## 作品集网站入口

- 根目录的 `index.html` 是「内容、营销与增长作品集」。建议使用本地预览地址查看视频。
- `portfolio-editor.html` 提供账号和视频填写表单：保存本机草稿、预览，再导出更新文件。
- `portfolio-data.js` 存放项目账号、视频链接、背景、创作思路和职责。
- `style.css` 管理外观，`script.js` 管理语言和案例，`gallery.js` 与 `video-utils.js` 管理视频。
- `assets/` 存放作品图片；现有图片和水印均保留。
- `02-网页简历/` 是原有经历介绍页，新作品集底部保留入口。
- 新版作品集的使用、发布、备份和恢复说明见 `99-项目记录/作品集改版说明.md`。

## 文件夹说明

- `01-个人知识库`: 存放我的职业经历、项目案例、能力证据、岗位定制需求等长期素材。
- `02-网页简历`: 我的个人简历网页，双击 `index.html` 可以本地预览。
- `03-简历生成工具`: 生成 Word 简历的脚本工具。
- `04-简历输出`: 已生成的 Word 简历等成品文件。
- `99-项目记录`: 对话恢复记录、过程记录、临时说明等归档内容。

## 推荐使用方式

1. 新增职业素材时，先放进 `01-个人知识库/00-快速投喂区.md`。
2. 新增账号或视频时，打开 `portfolio-editor.html` 填写并保存；正式发布前先预览。要更新经历介绍页时，修改 `02-网页简历`。
3. 要生成 Word 简历时，使用 `03-简历生成工具/build_general_resume.py`。
4. 生成后的简历统一放在 `04-简历输出`。
5. 不确定放哪里时，先放进 `99-项目记录`，后续再整理。
