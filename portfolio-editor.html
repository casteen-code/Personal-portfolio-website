视频与背景

支持抖音、TikTok、YouTube、Bilibili 完整视频链接，以及 MP4。其他来源保留原页观看入口。

填入后优先播放这个文件，上方链接保留为原视频入口。先把下载的视频放入网站的 assets/videos 文件夹；这里填写文件位置，不会自动上传视频。

如何更新到正式网站？
  1. 先保存项目、账号或作品，然后点「预览已保存草稿」。
  2. 确认内容后，点「导出更新文件」，得到 portfolio-data.js 文件。
  3. 将文件交给我更新，或替换 GitHub 项目中的同名文件。只有正式提交后，线上访客才会看到更新。
  4. 修改前点「备份草稿」保存一份副本；需要恢复时点「导入备份」。

抖音 / TikTok 的分享短链接需要先打开，并复制跳转后的完整视频网址。视频可能因平台权限、地区限制或删除而无法播放，页面会保留原链接。封面须使用可公开访问的图片链接；本地图片需要先加入网站的 assets 文件夹。
