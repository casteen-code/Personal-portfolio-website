## 如何添加作品

1. 打开「管理账号与视频」，选择项目；也可以新增项目。
2. 填写项目介绍、主页链接，点击「保存项目与账号」。一个项目可以有多个账号。
3. 在右侧填写标题、单条视频链接、封面（可选）、背景、思路、职责和真实表现。
4. 已有下载文件时，先放入 `assets/videos/`，再在「站内播放文件」填入对应位置。该文件优先播放，原平台链接继续保留。没有下载文件可留空。
5. 点击「保存这条作品」，然后「预览已保存草稿」。鼠标悬停、手机点击和播放器均可直接查看。
6. 满意后点「导出更新文件」，得到 `portfolio-data.js`。把它交给网站维护流程更新，或者替换仓库里的同名文件。

草稿只存在当前浏览器，不会自动写入网站文件，也不会影响其他访客。正常首页只读取网站保存的数据；带 `?preview=draft` 的页面才读取当前浏览器草稿。「备份草稿」可导出 JSON，「导入备份」可恢复。不同浏览器、本地地址和正式网站的草稿互不相通。

暂不填写的背景、思路、职责或表现字段会隐藏，不会自动生成个人经历。英文文案未填写时，使用原文。

## 视频来源与限制

- 接入官方播放器的完整单条链接：抖音、TikTok、YouTube、Bilibili。也支持可公开访问的 MP4 / WebM / OGG 文件。
- 抖音/TikTok 分享短链接应先打开，再复制地址栏中包含视频编号的完整网址。编辑器会识别短链接并提示，不会猜测视频编号。
- 账号主页不能用作单条视频播放器。飞书、Instagram、其他不支持的来源保留「打开作品」入口。
- 第三方平台仍可能要求登录、限制地区或禁止嵌入。播放器连接缓慢时有封面和状态提示，且始终显示原视频入口。
- **realme 示例已改为站内 MP4，并验证实际播放与进度跳转。** 之前无法连接的 TikTok 嵌入播放器不再用于这条视频。其他没有本地文件的作品，仍可能受第三方播放器限制。
- 无自动抓取全部账号视频、同步播放量或粉丝数功能。
- 没有云端管理后台、多人编辑、自动上传视频或自动发布功能。
- JavaScript 关闭时仍可打开原有案例图片；分组、编辑器和视频弹窗需要 JavaScript。
- 原图文字保持原语言，网页语言切换不会翻译图片。

官方接入文档：
- [TikTok Embed Player](https://developers.tiktok.com/docs/en/embed-player)
- [抖音官方 IFrame 播放器](https://developer.open-douyin.com/docs/resource/zh-CN/dop/develop/openapi/video-management/douyin/iframe-player)
- [YouTube Player Parameters](https://developers.google.com/youtube/player_parameters)
- [Bilibili 官方播放器](https://player.bilibili.com/)
